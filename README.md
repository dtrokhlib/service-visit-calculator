# Калькулятор вартості виїзду

Vue 3 + TypeScript + Vite. Дві сторінки розрахунку, кілька міст замовника, окремий вибір HAAS/SWD для кожної локації. Розрахунок лише виїзду, без роботи й проживання.

## Локальний запуск

Node.js 22.12+. Виконайте `npm install`, потім `npm run dev`. Для пошуку міст потрібен локальний `.env` зі змінною `VITE_GEOAPIFY_API_KEY`. Зразок — `.env.example`. Після зміни ключа перезапустіть Vite.

Міста України шукає Geoapify; автомобільні відстані обчислює Route Matrix API. Координати представництв — точки міст, не фактичні адреси офісів. Після зміни міста чи типу верстатів попередній результат локації скидається. Недоступні маршрути позначаються явно.

## Тарифи

Редагуйте `public/config.json` та перезавантажте сторінку. `perKmGrossUah` — 24 грн з ПДВ за км, `minimumVisitGrossUah` — 9600 грн з ПДВ (8000 без ПДВ), `vatRate` — 0.2. Поки тарифи орієнтовні. Списки міст і координат — `representations.HAAS` та `representations.SWD`. Для кожного списку потрібні унікальні id та коректні координати `[longitude, latitude]`.

Формула: `max(9600, відстань в один бік × 2 × 24)`, після чого округлення вгору до кратної 6 грн. Сума без ПДВ = результат × 5/6; ПДВ = результат / 6. Усі суми цілі. Наприклад, 200 км — 9600/8000 грн із/без ПДВ, 200.001 км — 9606/8005 грн, 300 км — 14400/12000 грн. Арифметика враховує метри маршруту; проміжне округлення ціни не виконується. Для іншої ставки ПДВ необхідно переглянути правило округлення; поточна конфігурація допускає лише 20%.

Кожен рядок — альтернативне представництво, ціни не підсумовуються. Після розрахунку доступна кнопка друку: виберіть PDF у системному діалозі. Друкуються також суми без ПДВ і ПДВ. Головна сторінка відкриває кілометровий калькулятор; зональний доступний через перемикач.

## Перевірка

`npm test`, `npm run check:public`, `npm run build`. Результат збірки — `dist/`. Браузерну перевірку виконайте через `npm run dev`: додайте HAAS і SWD для різних міст, отримайте 8 і 3 варіанти відповідно, змініть тип, повторіть розрахунок, перевірте PDF.

## Публічні файли

`.env`, `dist/`, залежності та внутрішній бізнес-документ виключені з Git. Перевірка `check:public` шукає явні ключі й приватні файли без виведення їх значень; це не повний аудит секретів. Geoapify-ключ є браузерним і видимий у зібраному коді: обмежуйте його дозволеними доменами. `config.json` публічний — не додавайте персональні адреси інженерів чи секрети.

Поточний workflow GitHub Pages збережений; для цієї зміни його не потрібно запускати до завершення локальної перевірки. Під час майбутньої публікації передайте ключ через GitHub Secrets `VITE_GEOAPIFY_API_KEY`, увімкніть Pages із джерелом GitHub Actions. `VITE_BASE_PATH` визначає шлях розміщення, типовий — `/`. Локальний запуск не потребує GitHub або CI/CD.

## Зональний калькулятор

Доступні дві сторінки: `/#/kilometers` та `/#/zones`. Введені міста, HAAS/SWD та отримані маршрути зберігаються при перемиканні. Зональний тариф — мінімальна вартість × множник, без додавання кілометрової оплати: до 100 км включно ×1 (9600 грн із ПДВ), понад 100 до 500 км не включно ×2 (19200 грн), від 500 км ×3 (28800 грн). Відстань в один бік. Межі й множники налаштовуються в `config.json` → `zones`. Округлення та виділення ПДВ однакові для обох моделей. PDF містить назву обраної моделі й відповідні суми. Робота та проживання не включені.
